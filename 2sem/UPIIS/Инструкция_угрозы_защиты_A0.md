# Инструкция: добавление угроз и защит на декомпозицию A0

## 1. Что и куда добавляем (общая схема)

Все 3 угрозы и 3 защиты размещаются **на декомпозиции A0** (где уже есть 5 блоков A1–A5).

Соответствие угроз процессам, которые они атакуют:

| № | Угроза (БДУ) | Атакует блок | Защита |
|---|---|---|---|
| 1 | УБИ.221 — отравление обучающих данных | **A2** «Собирать и предобрабатывать данные» | Санитизация и валидация выборок |
| 2 | УБИ.017 — DoS на шлюз приёма | **A2** «Собирать и предобрабатывать данные» | Rate Limiting |
| 3 | УБИ.042 — подмена системных логов | **A5** «Формировать отчёты и реагировать» | Неизменяемый журнал аудита |

Нумерация добавляемых блоков (продолжаем нумерацию A1–A5):

- **Красные (угрозы):** A6, A7, A8
- **Зелёные (защиты):** A9, A10, A11

> В примере на фото нумерация шла A226–A231 (от родительского A22). У вас родитель — A0, поэтому A6–A11.

---

## 2. Размещение блоков на листе A0

Существующие 5 блоков идут по диагонали из левого верхнего угла в правый нижний:
```
A1
   A2
      A3
         A4
            A5
```

Добавляем 6 новых блоков по периметру так, чтобы не пересекать диагональ:

```
[A9 зел.]              [A11 зел.]
    │                      │
    ↓                      ↓
A1                        
   A2 ← [A6 кр.] [A7 кр.]
      A3                   
         A4                
            A5 ← [A8 кр.]  
                  ↑        
              (А11 страхует A5)
```

Размер новых блоков — **6×3 см**, как у обычных. Цвет заливки:
- **Красная заливка / красная рамка** — блоки A6, A7, A8 (угрозы)
- **Зелёная заливка / зелёная рамка** — блоки A9, A10, A11 (защиты)

Конкретные координаты на листе A3 (альбомная):

| Блок | Позиция на листе | Цвет |
|---|---|---|
| A6 ОТРАВЛЯТЬ ОБУЧАЮЩИЕ ДАННЫЕ | Снизу под A2 (ниже диагонали, слева-центр) | красный |
| A7 БЛОКИРОВАТЬ ШЛЮЗ ПРИЁМА ДАННЫХ | Снизу под A2, справа от A6 | красный |
| A8 ПОДМЕНЯТЬ ЗАПИСИ ЖУРНАЛА СОБЫТИЙ | Снизу под A5 (нижний правый угол листа) | красный |
| A9 САНИТИЗИРОВАТЬ ОБУЧАЮЩИЕ ВЫБОРКИ | Сверху над A2 (выше диагонали) | зелёный |
| A10 ОГРАНИЧИВАТЬ ЧАСТОТУ ЗАПРОСОВ | Сверху над A2, правее A9 | зелёный |
| A11 ВЕСТИ НЕИЗМЕНЯЕМЫЙ ЖУРНАЛ АУДИТА | Сверху-справа над A5 | зелёный |

```

────────────────────────

```

## 7. Контрольный список перед сдачей

- [ ] На листе A0 ровно **11 блоков**: 5 белых (A1–A5) + 3 красных (A6–A8) + 3 зелёных (A9–A11).
- [ ] Каждая угроза втыкается стрелкой в тот процесс, который она ломает (A6→A2, A7→A2, A8→A5).
- [ ] Каждая защита идёт И в защищаемый процесс (A9/A10→A2, A11→A5), И в свою угрозу (A9→A6, A10→A7, A11→A8).
- [ ] У каждого нового блока есть хотя бы один вход (I), одно управление (C), один механизм (M).
- [ ] Метки стрелок написаны строчными существительными, имена блоков — ПРОПИСНЫМИ глаголами.
- [ ] В углу листа — легенда.
- [ ] Названия угроз в блоках совпадают (по смыслу) с записями в таблице раздела 4.4.3 ТЗ.
